## Dimensions

PCB dimensions: 60.0mm x 61.5mm
Case Dimension: 81.9mm x 80.4mm

## BOM

- 5x Cherry MX Key Switches
- 1x Rotary Encoder With Switch
- Seeduino XIAO RP2040
- 3D Printing
- PCB Manifacture
